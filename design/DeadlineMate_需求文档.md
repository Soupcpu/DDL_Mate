# Deadline Mate / 时限管家 需求文档

## 1. 文档说明

本文档用于指导 Deadline Mate Android App 的功能设计、页面实现、数据结构设计和后续开发。

项目目标是开发一个高质量 Deadline 管理 App，支持手动添加、语音添加、截图识别、日历查看、优先级排序、任务提醒和完成反馈。

## 2. 功能总览

App 包含 5 个主要页面：

```text
首页 Home
日历 Calendar
添加任务 Add Task
优先级 Priority
我的 Profile
```

底部导航固定显示：

```text
首页 / 日历 / 添加 / 优先级 / 我的
```

## 3. 首页 HomeScreen

### 3.1 页面目标

首页用于展示用户当前最需要关注的 Deadline。

用户打开 App 后，应快速知道：

- 今天有什么要截止
- 本周还有多少任务
- 哪些任务最紧急
- 当前建议先处理什么

### 3.2 页面内容

首页包含：

1. 顶部日期与标题
2. 本周任务概览卡
3. 三个统计卡
4. 今日状态建议卡
5. 临近 Deadline 任务列表

### 3.3 顶部区域

显示：

```text
今天 · 5月7日
待办概览
```

右上角可以有一个轻量添加入口，但底部中间的添加按钮仍然是主要入口。

### 3.4 本周任务概览卡

展示：

```text
本周剩余任务
8 个
2 个即将截止
```

视觉上使用深色渐变卡片。

### 3.5 统计卡

三个统计卡：

```text
今日截止：3
重要紧急：2
已完成：5
```

图标规则：

```text
今日截止 → 红底白字「今」
重要紧急 → 橙底白字「急」
已完成 → 绿底白字「完」
```

### 3.6 今日状态建议卡

示例：

```text
建议先处理：数据库实验报告
距离截止还有不到 4 小时，且属于重要紧急任务。
```

图标使用任务首字：

```text
数据库实验报告 → 数
```

### 3.7 临近 Deadline 任务列表

任务卡包含：

- 任务首字图标
- 任务名称
- 简短备注
- 优先级标签
- 截止时间

示例：

```text
图标：数
标题：数据库实验报告
描述：SQL 文件、截图和实验总结
标签：重要紧急
时间：今晚 23:59
```

任务卡图标颜色规则：

```text
逾期 / 24小时内截止：红色
3天内截止：橙色
7天内截止：黄色
7天以上：蓝色或灰色
已完成：绿色
```

## 4. 添加任务 AddTaskScreen

### 4.1 页面目标

添加任务页负责录入 Deadline。

添加任务页包含三种模式：

```text
手动
语音
截图
```

三种模式以卡片按钮展示，使用文字图标：

```text
手动 → 手
语音 → 声
截图 → 图
```

### 4.2 手动模式

手动模式显示完整表单。

字段：

```text
任务名称
截止日期
截止时间
重要性
提醒时间
重复规则
任务类型
备注
保存按钮
```

#### 任务名称

必填。

示例：

```text
提交数据库实验报告
AI Coding 项目提交
英语测试复习
```

#### 截止日期

必填。

#### 截止时间

可选。  
如果用户不填写，默认设置为当天 23:59。

#### 重要性

选项：

```text
高
中
低
```

#### 提醒时间

选项：

```text
截止前 1 天
截止前 3 小时
截止前 30 分钟
不提醒
```

后期可扩展为多提醒。

#### 重复规则

选项：

```text
不重复
每天
每周
每月
自定义
```

适用场景：

```text
每天背单词
每周写总结
每月提交材料
每周复习算法
```

#### 任务类型

选项：

```text
学习
作业
比赛
会议
生活
其他
```

#### 备注

用于填写提交方式、注意事项等。

### 4.3 语音模式

语音页参考微信语音输入。

页面结构：

```text
上方：语音识别文字区域
中间：识别字段标签
底部：按住说话按钮
```

交互流程：

```text
用户按住「按住说话」
↓
开始录音
↓
用户松开按钮
↓
停止录音
↓
语音转文字
↓
显示识别结果
↓
系统提取任务字段
↓
进入任务草稿确认页
↓
用户微调
↓
保存
```

默认提示：

```text
按住下方按钮开始说话，识别后的文字会显示在这里。确认后进入任务草稿，可继续手动微调任务名称、截止时间、重要性和重复规则。
```

示例语句：

```text
明天晚上八点提醒我提交数据库实验报告，重要性高，每周重复。
```

应解析为：

```text
任务名称：提交数据库实验报告
截止时间：明天 20:00
重要性：高
重复规则：每周
```

注意：语音识别结果不能直接保存，必须进入确认编辑流程。

### 4.4 截图模式

截图页保持简洁，只保留核心动作。

页面内容：

```text
标题：选择一张截图
说明：从相册选择通知、课程平台或比赛要求截图，识别后自动整理为任务草稿。
按钮：打开相册
```

交互流程：

```text
用户点击「打开相册」
↓
系统打开相册
↓
用户选择图片
↓
OCR 识别图片文字
↓
系统提取任务名称、截止时间、提交要求等信息
↓
生成任务草稿
↓
用户手动确认 / 微调
↓
保存任务
```

截图识别适用场景：

```text
微信群通知截图
课程平台作业截图
比赛提交要求截图
老师发布的任务截图
会议通知截图
```

注意：截图识别结果不能直接保存，必须进入确认编辑流程。

## 5. 日历 CalendarScreen

### 5.1 页面目标

日历页用于查看任务在时间上的分布。

支持：

```text
周历
月历
```

右上角使用文字按钮切换：

```text
月历 / 周历
```

### 5.2 周历模式

展示本周 7 天：

- 星期
- 日期
- 是否有任务的小圆点

点击某一天后，下方显示当天任务时间线。

示例：

```text
10:00 算法复习
20:00 数据库实验报告
23:59 最终 Deadline
```

### 5.3 月历模式

展示本月完整日期。

要求：

1. 顶部显示当前年月。
2. 左右按钮切换上个月 / 下个月。
3. 有任务的日期显示小圆点。
4. 今天用蓝色高亮。
5. 点击某一天后显示当天任务。

## 6. 优先级 PriorityScreen

### 6.1 页面目标

优先级页用于告诉用户“先做什么”。

不使用传统四象限，因为四象限在手机屏幕上容易拥挤，不够直观。

改为任务队列：

```text
马上处理
计划推进
可延后
```

### 6.2 顶部总结卡

示例文案：

```text
先完成最容易拖慢节奏的任务
```

要求：

- 深色卡片
- 白色文字
- 加粗
- 大字号
- 简洁有力量

### 6.3 马上处理

展示：

- 已逾期任务
- 今天截止任务
- 24 小时内截止任务
- 重要性高且临近截止的任务

### 6.4 计划推进

展示：

- 重要但不马上截止的任务
- 需要持续推进的任务
- 重复任务

### 6.5 可延后

展示：

- 不紧急任务
- 重要性低任务
- 没有明确截止压力的任务

### 6.6 优先级算法建议

分数越高越优先。

规则示例：

```text
已逾期：+100
24小时内截止：+80
3天内截止：+50
7天内截止：+30
重要性高：+40
重要性中：+20
重要性低：+5
重复任务：+10
```

## 7. 我的 ProfileScreen

### 7.1 页面目标

我的页负责设置、历史和正反馈。

完成度、历史记录不要放在首页第一屏。

### 7.2 页面内容

包括：

```text
用户信息
本周完成度
连续完成天数
最近完成任务
通知提醒设置
默认提醒时间
语音识别设置
主题样式
```

### 7.3 完成反馈

示例：

```text
本周完成度：76%
已完成 13 / 17 个任务
连续完成：6 天
```

最近完成记录：

```text
英语单词复习 今天 18:20 准时
会议通知整理 昨天 21:10 提前
```

## 8. 数据模型

### 8.1 Task

```kotlin
data class Task(
    val id: Long = 0,
    val title: String,
    val description: String? = null,
    val deadlineDateTime: Long,
    val importance: ImportanceLevel,
    val urgency: UrgencyLevel,
    val status: TaskStatus,
    val category: TaskCategory,
    val repeatRule: RepeatRule,
    val reminderEnabled: Boolean,
    val reminderMinutesBefore: Int?,
    val createdAt: Long,
    val updatedAt: Long,
    val completedAt: Long? = null
)
```

### 8.2 枚举

```kotlin
enum class ImportanceLevel {
    HIGH, MEDIUM, LOW
}

enum class UrgencyLevel {
    OVERDUE, HIGH, MEDIUM, LOW
}

enum class TaskStatus {
    TODO, IN_PROGRESS, DONE, EXPIRED
}

enum class TaskCategory {
    STUDY, HOMEWORK, COMPETITION, MEETING, LIFE, OTHER
}

enum class RepeatRule {
    NONE, DAILY, WEEKLY, MONTHLY, CUSTOM
}
```

### 8.3 TaskDraft

语音和截图识别后生成 TaskDraft，而不是直接保存为 Task。

```kotlin
data class TaskDraft(
    val title: String? = null,
    val description: String? = null,
    val deadlineDateTime: Long? = null,
    val importance: ImportanceLevel? = null,
    val repeatRule: RepeatRule? = null,
    val category: TaskCategory? = null,
    val rawText: String? = null
)
```

## 9. 通知提醒需求

提醒方式：

```text
截止前 1 天
截止前 3 小时
截止前 30 分钟
不提醒
```

技术建议：

- AlarmManager
- BroadcastReceiver
- NotificationManager

需要考虑 Android 13+ 通知权限。

## 10. MVP 功能范围

第一版必须完成：

1. 手动添加任务
2. 本地保存任务
3. 首页展示临近任务
4. 任务按截止时间排序
5. 显示今日截止数量
6. 显示重要紧急数量
7. 显示已完成数量
8. 日历页查看任务
9. 优先级页按规则分组
10. 我的页查看完成度和历史
11. 标记任务完成
12. 删除任务

语音和截图可以先完成 UI 与接口占位。

## 11. 非功能需求

1. UI 简洁干净，保持轻工具感。
2. 页面适合单手操作。
3. 避免使用颜色相近的 emoji 和背景。
4. 所有智能识别结果都必须进入确认编辑流程。
5. 首页不堆复杂统计。
6. 添加任务入口位于底部导航中间。
7. 代码结构清晰，方便后续扩展。
