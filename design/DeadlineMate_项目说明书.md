# Deadline Mate / 时限管家 项目说明书

## 1. 项目名称

**Deadline Mate**

中文名暂定为：**时限管家**

## 2. 项目定位

Deadline Mate 是一款面向学生、课程任务较多用户、比赛项目参与者、社团/活动组织者的 Android Deadline 管理 App。

它不是普通待办清单，而是围绕「截止时间」「重要性」「紧急程度」「提醒」「日历」「优先级排序」构建的任务管理工具。

核心目标是帮助用户解决以下问题：

1. 任务太多，容易忘记截止时间。
2. 不同任务的重要程度和紧急程度容易混淆。
3. 临近 Deadline 时缺少明显提醒。
4. 手动录入任务成本较高。
5. 微信群通知、课程平台截图、比赛通知截图中有大量 Deadline 信息，用户不想手动整理。
6. 用户打开 App 后，最想知道的是“现在该做什么”，而不是看到复杂统计。

## 3. 目标用户

### 3.1 核心用户

- 大学生
- 课程作业较多的学生
- 需要同时处理比赛、课程、社团、项目任务的人
- 经常收到通知截图、课程平台提醒、微信群任务通知的人
- 需要管理重复性任务的人，例如每天背单词、每周复习、每月提交材料

### 3.2 使用场景

1. 用户收到老师发布的作业通知，需要快速记录截止时间。
2. 用户参加比赛，需要记录项目提交日期。
3. 用户每天有固定任务，例如背单词、算法复习、健身打卡。
4. 用户从微信群或课程平台截图中提取任务信息。
5. 用户想快速查看本周还有哪些 Deadline。
6. 用户想知道当前最应该先处理哪件事。

## 4. 产品核心理念

### 4.1 首页只解决一个问题：现在该做什么

首页不堆复杂功能，不把完成度和历史记录放在第一屏。

首页重点展示：

- 今天截止的任务
- 本周剩余任务
- 重要紧急任务
- 临近 Deadline
- 当前建议优先处理的任务

### 4.2 添加任务必须足够方便

任务添加是高频操作，因此底部导航中间保留「添加」入口。

添加任务支持三种方式：

1. 手动输入
2. 语音输入
3. 截图识别

### 4.3 智能识别结果不能直接保存

语音输入和截图识别都可能出错，因此识别结果必须进入确认编辑流程。

标准流程：

```text
语音 / 截图输入
↓
系统识别内容
↓
提取任务草稿
↓
用户确认 / 微调
↓
保存任务
```

### 4.4 视觉风格强调轻工具感

整体视觉参考：

- iOS 卡片感
- 清浊 App 的轻量工具感
- 简洁、干净、实用
- 不做花哨宣传页
- 不滥用 emoji

## 5. 主要功能模块

### 5.1 首页模块

首页展示：

- 当前日期
- 本周任务概览
- 今日截止数量
- 重要紧急数量
- 已完成数量
- 今日状态建议
- 临近 Deadline 列表

### 5.2 添加任务模块

添加任务页包含三种模式：

- 手动
- 语音
- 截图

手动模式提供完整表单。  
语音模式类似微信语音输入。  
截图模式打开相册选择图片进行识别。

### 5.3 日历模块

日历模块支持：

- 周历
- 月历

用户可以通过日历查看任务在时间上的分布。

### 5.4 优先级模块

不使用传统四象限页面，改为更适合手机端的优先级队列：

- 马上处理
- 计划推进
- 可延后

优先级根据截止时间、重要性、是否逾期、重复任务等因素计算。

### 5.5 我的模块

我的页展示：

- 用户信息
- 本周完成度
- 连续完成天数
- 最近完成记录
- 通知提醒设置
- 默认提醒时间
- 语音识别设置
- 主题样式

## 6. 页面结构

底部导航栏包含五个 Tab：

```text
首页 / 日历 / 添加 / 优先级 / 我的
```

中间的「添加」入口是高频入口，可以略微突出，但不能过度悬浮或破坏底部导航一致性。

## 7. 视觉设计规范

### 7.1 整体关键词

- 简洁
- 干净
- 轻量工具感
- 信息层级清晰
- 大圆角
- 浅灰背景
- 白色或半透明卡片
- 低饱和色彩
- 细边框
- 柔和阴影

### 7.2 推荐配色

```text
背景色：#F5F5F7 / #F8FAFC
主色：#007AFF
危险色：#FF3B30
警告色：#FF9500
黄色提醒：#F7B500
完成色：#34C759
文字色：#1D1D1F
辅助文字：#86868B
边框：rgba(60,60,67,0.12)
```

### 7.3 图标规则

避免使用颜色相近的 emoji 叠加在同色背景上。

错误示例：

```text
红色背景 + 红色闹钟 emoji
橙色背景 + 橙色闪电 emoji
```

正确规则：

首页统计卡使用文字图标：

```text
今日截止 → 红底白字「今」
重要紧急 → 橙底白字「急」
已完成 → 绿底白字「完」
```

任务卡使用任务标题首字：

```text
数据库实验报告 → 数
AI Coding 项目提交 → A
英语测试复习 → 英
```

添加页三种输入方式使用文字图标：

```text
手动 → 手
语音 → 声
截图 → 图
```

这些文字图标需要设计成圆角色块，使用低饱和渐变背景、细边框、加粗字体、居中对齐。

## 8. 数据模型概述

核心实体是 Task。

Task 应包含：

- id
- title
- description
- deadlineDateTime
- importance
- urgency
- status
- category
- repeatRule
- reminderEnabled
- reminderMinutesBefore
- createdAt
- updatedAt
- completedAt

语音和截图识别结果应先生成 TaskDraft，而不是直接生成 Task。

## 10. 开发优先级

第一版 MVP 必须完成：

1. 手动添加任务
2. 本地保存任务
3. 首页展示临近任务
4. 任务按截止时间排序
5. 显示今日截止数量
6. 显示重要紧急数量
7. 显示已完成数量
8. 日历页查看任务
9. 优先级页按规则分组
10. 我的页查看完成度和历史
11. 标记任务完成
12. 删除任务

语音和截图功能可以先完成 UI 和接口占位，再逐步接入真实能力。

## 11. 项目最终目标

做出一个简洁、实用、好看的 Deadline 管理工具。

产品重点不是普通待办清单，而是围绕 Deadline、优先级、日历、提醒、语音输入、截图识别和确认编辑流程，构建一个适合学生和任务密集用户长期使用的 App。
