# Deadline Mate 可用性审查 - 主题、图标与日历

审查时间：2026-05-10

## 本轮已验证

- 应用可以正常构建：`.\gradlew.bat :app:assembleDebug` 通过。
- APK 可以安装并启动到模拟器。
- 应用图标已改为 adaptive icon 叠层：背景使用 `icon/ic_launcher_background.png`，前景使用 `icon/ic_launcher_foreground.png`。
- 主题设置已收敛为 3 项：跟随系统、亮色、暗色。
- 亮色模式已改为温和米白背景和低饱和棕色主色。
- 暗色模式已恢复为接近旧高对比模式的灰底、深色主卡片风格。
- 首页大卡片、优先级顶部卡片、底部导航、日历选中日期、添加页主按钮均能跟随当前主题主色。
- 周历已从 7 天扩展为 14 天，显示本周和下周。
- 日历任务点已区分状态：存在未完成任务显示红点，某天任务全部完成显示绿点。
- 月历模式仍可进入，月份切换箭头可见，日期任务点可显示绿色完成状态。

## 仍建议后续处理的问题

1. 部分语义图标仍保留固定蓝色

   例如首页空任务卡片里的“任”、底部“我的”图标等仍使用固定系统蓝色。它们不影响功能，但在米白主题下会显得不完全统一。

2. 暗色模式目前是“旧高对比风格”，不是完整黑色夜间模式

   这是按当前需求处理的结果。若后续要做真正暗色模式，需要把 `AppText`、`AppCard`、`AppLine`、`GlassPanel` 等全局颜色改成 CompositionLocal 或 Material colorScheme 统一控制。

3. Android 状态栏和导航栏颜色仍来自原生样式

   当前页面背景已随主题变化，但系统状态栏/导航栏样式没有完全动态联动。建议后续在 `MainActivity` 中根据主题同步设置 system bars。

4. 旧颜色配置迁移目前采用自动归一

   以前保存过的蓝色、绿色、紫色、橙色、高对比会自动变成“跟随系统”。逻辑简单可靠，但没有做一次性迁移标记。

5. 应用图标只配置了 adaptive icon

   项目 `minSdk` 为 26，所以 adaptive icon 足够使用。如果以后下调最低版本，需要补充传统 mipmap 密度图标。

## 本轮结论

核心功能没有发现阻断性问题。主题、图标、周历两周展示和任务完成状态标记已按本轮要求落地；剩余问题主要是视觉一致性和系统栏联动层面的优化。
